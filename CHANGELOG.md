# Changelog

## 0.1.0 (2026-10-29)

First release.

- Agent templates: instructions plus three skills (job-application-workflow, job-discovery, referral-first) and suggested prompts
- `huntpilot render` for Copilot Studio, Claude Projects and custom GPTs
- `huntpilot check` for unfilled placeholders, banned words and instruction length
- `huntpilot score` deterministic fit pre-score with hard filters and variant pick
- `huntpilot tracker` Excel tracker with the `Applications` table and `ID` key column
- `huntpilot evals` 14 test cases rendered as a checklist
- Setup guides for Copilot Studio, Claude Projects and custom GPTs; testing and publishing guides
